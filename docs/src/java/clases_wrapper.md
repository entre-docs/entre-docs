# Clases Wrapper

Son clases que envuelven a los datos primitivos para transformarlos en objetos. Tienen un dato primitivo asociado.

| Tipo primitivo | Clase Wrapper |
|--------|--------|
| `int` | `Integer` |
| `double` | `Double` |
| `float` | `Float` |
| `long` | `Long` |
| `boolean` | `Boolean` |
| `char` | `Character` |
| `byte` | `Byte` |
| `short` | `Short` |
