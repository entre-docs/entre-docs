# Fundamentos del lenguaje Java

## Variables

Espacio de memoria donde se almacena un valor que puede cambiar durante la ejecución del programa.
Una variable sin inicializar tiene valor por defecto 0 (si el tipo de dato es int).

```java
int      edad       ;
 ↓        ↓         ↓ 
tipo    nombre    fin de
de                sentencia
dato
```


## Constantes

Espacio en memoria donde se almacena un valor que **no** puede cambiar durante la ejecución de un programa. **NO tiene valor por defecto**.

```java
final     int       edad       ;
  ↓        ↓         ↓         ↓
modi-    tipo      nombre   fin de
fica-     de               sentencia
dor      dato
```
